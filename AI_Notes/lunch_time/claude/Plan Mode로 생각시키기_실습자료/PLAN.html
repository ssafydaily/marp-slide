1개발 진행 단계

원본 계획서: ../resource/001_계획 요청/004-2_Todo_리스트_앱_개발_계획서.md

6 / 6 단계 완료
  • 1.프로젝트 환경 준비 — Vite로 Vue3 프로젝트 생성, 기본 폴더 구조 잡기
  • 2.기본 화면 뼈대 구성 — 입력창 + 목록 영역 배치
  • 3.핵심 기능 구현 — 추가 / 삭제 / 완료 체크 / 수정
  • 4.자동 저장 기능 연결 — localStorage와 연동해 새로고침해도 데이터 유지
  • 5.화면 다듬기 — 기본 스타일 정리(입력창·버튼·완료 표시·hover 등)
  • 6.전체 점검 및 마무리 확인 — 브라우저에서 추가/완료/수정/삭제/새로고침 유지까지 직접 확인 완료

2완료 기준 체크

  • 할 일을 입력하고 등록하면 목록에 바로 보인다
  • 체크박스를 누르면 완료 표시(취소선)가 되고, 다시 누르면 취소된다
  • 목록에서 특정 할 일의 내용을 수정할 수 있다
  • 목록에서 특정 할 일을 삭제할 수 있다
  • 화면 어딘가에 "남은 할 일 개수"가 표시된다
  • 새로고침하거나 브라우저를 껐다 켜도 목록이 그대로 남아 있다
기본 버전(계획서 범위)은 위 항목이 모두 충족되어 완료된 상태입니다.

3추후에 진행할 수 있는 기능

계획서에서 이번 범위에는 제외했던 항목과, 자연스럽게 이어질 수 있는 개선 항목입니다.

  • 로그인/회원가입 — 사용자별로 할 일 목록을 구분
  • 여러 기기 간 동기화 — 서버 없이 로컬 저장소만으로는 불가능, 백엔드 연동 필요
  • 서버/데이터베이스 저장 — 브라우저를 바꾸거나 초기화해도 데이터 유지
  • 카테고리 분류 — 할 일을 업무/개인 등으로 태그 구분
  • 우선순위 설정 — 중요도에 따라 정렬 또는 강조 표시
  • 마감일 설정 — 날짜 지정 및 임박한 항목 알림
  • 필터/보기 전환 — 전체 / 진행 중 / 완료된 항목만 보기
  • 검색 기능 — 목록이 길어졌을 때 키워드로 찾기
  • 드래그로 순서 변경 — 할 일 우선순위를 직접 끌어서 재정렬
