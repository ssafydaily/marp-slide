1프로젝트 배경과 목적

할 일을 메모지나 메신저 대화방에 흩어서 적어두면 놓치기 쉽고, 무엇이 끝났고 무엇이 남았는지 한눈에 파악하기도 어렵습니다. 이런 불편을 줄이기 위해 누구나 웹 브라우저만 열면 바로 쓸 수 있는 가벼운 Todo(할 일) 리스트 앱을 만들고자 합니다.

이 문서는 실제 개발에 들어가기 전에 "무엇을, 어떤 순서로, 어디까지 만들 것인지"를 미리 정리한 계획서입니다. 개발 전에 범위와 순서를 명확히 해두면, 작업 중간에 방향이 흔들리거나 빠뜨리는 기능 없이 효율적으로 진행할 수 있습니다.

비유하자면, 인테리어 공사를 할 때 견적서와 도면 없이 바로 공사를 시작하면 나중에 자재가 안 맞거나 마감이 어긋나는 것과 같습니다. 이 문서는 공사를 시작하기 전에 그리는 "설계 도면"에 해당합니다.

2한눈에 보는 용어 설명

개발 용어가 낯선 분들을 위해, 이 문서와 이후 개발 과정에서 자주 나올 단어를 미리 쉬운 말로 풀어드립니다.

Vue3 (뷰3)
화면을 블록처럼 조립해서 만들 수 있게 도와주는 도구입니다. "버튼", "목록" 같은 화면 부품을 만들어 놓고 재사용할 수 있습니다.
Vite (비트)
개발 중인 화면을 저장하자마자 바로 브라우저에 반영해 보여주는 빠른 작업실입니다. 수정 → 확인을 빠르게 반복할 수 있게 해줍니다.
컴포넌트
화면을 이루는 하나의 부품(블록)입니다. 예: "할 일 입력창" 부품, "할 일 한 줄" 부품.
상태(state)
앱이 지금 기억하고 있는 정보입니다. 예: 지금까지 입력된 할 일 목록, 완료된 항목이 무엇인지 등.
로컬 스토리지
사용하는 브라우저(예: Chrome) 안에 데이터를 저장해두는 공간입니다. 새로고침하거나 창을 닫았다가 다시 열어도 데이터가 남아 있게 해줍니다.

3만들 것 (기능 범위)

이번 버전에서는 기본 기능에 집중합니다.

포함하는 기능

번호기능설명
1할 일 추가입력창에 할 일을 쓰고 등록하면 목록에 새 줄로 추가됩니다.
2할 일 목록 보기지금까지 등록한 할 일이 목록 형태로 화면에 보입니다.
3완료 체크체크박스를 누르면 완료 상태로 표시되고, 글자에 취소선이 그어집니다.
4할 일 수정등록된 할 일의 내용을 다시 고칠 수 있습니다.
5할 일 삭제더 이상 필요 없는 할 일을 목록에서 지울 수 있습니다.
6남은 할 일 개수 표시"3개 남음"처럼 아직 완료하지 않은 항목 수를 보여줍니다.
7자동 저장브라우저(로컬 스토리지)에 자동 저장되어, 새로고침하거나 창을 닫았다 열어도 목록이 그대로 남아 있습니다.

이번 범위에서 제외하는 것

아래 기능들은 이번 "기본 버전"에는 포함하지 않으며, 필요하면 다음 단계에서 확장할 수 있습니다.

상태항목
제외로그인/회원가입 (사용자 구분 없이 혼자 쓰는 앱으로 시작)
제외여러 기기 간 동기화 (지금은 한 브라우저 안에서만 저장됨)
제외서버/데이터베이스 저장 (지금은 내 컴퓨터 브라우저에만 저장됨)
제외카테고리 분류, 우선순위, 마감일 설정 등 고급 기능

4사용할 기술

구성 요소선택이유
화면 제작 도구Vue 3화면 부품(컴포넌트) 단위로 만들고 재사용하기 좋아, 이후 기능을 추가하기도 수월합니다.
개발 환경Vite코드를 저장하는 즉시 화면에 반영되어 확인 속도가 빠릅니다.
데이터 저장 방식브라우저 로컬 스토리지별도 서버 없이도 "새로고침해도 안 사라지는" 경험을 바로 제공할 수 있습니다.
디자인기본 CSS기능 검증이 목적인 기본 버전이라 가볍게 시작합니다.

6완료 기준

아래 항목을 모두 만족하면 "기본 버전 완성"으로 봅니다.

  • 할 일을 입력하고 등록하면 목록에 바로 보인다
  • 체크박스를 누르면 완료 표시(취소선)가 되고, 다시 누르면 취소된다
  • 목록에서 특정 할 일의 내용을 수정할 수 있다
  • 목록에서 특정 할 일을 삭제할 수 있다
  • 화면 어딘가에 "남은 할 일 개수"가 표시된다
  • 새로고침하거나 브라우저를 껐다 켜도 목록이 그대로 남아 있다

7참고 사항 / 제약

  • 지금 버전은 내 컴퓨터의 브라우저 안에만 데이터가 저장됩니다. 다른 컴퓨터나 휴대폰에서는 같은 목록이 보이지 않습니다.
  • 여러 사람이 함께 쓰거나 여러 기기에서 동기화하려면, 이후 서버와 데이터베이스를 추가하는 확장이 필요합니다.
  • 이번 문서는 "계획서"이며, 실제 코드 작성은 이 계획이 확정된 다음 별도로 진행합니다.
