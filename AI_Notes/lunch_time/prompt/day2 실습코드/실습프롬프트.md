### 알고리즘 문제풀이 프롬프트
```
양의 정수 x, y가 3x + 5y = 512 를 만족하고, x와 y가 모두 완전제곱수 (1, 4, 9, 16, 25, ...)일 때를 모두 찾아줘. 
조건을 만족하는 (x, y) 순서쌍이 총 몇 개인지, 그리고 그중 x+y가 가장 큰 값은 얼마인지 알려줘. 
어떻게 찾았는지 과정도 보여줘.

```

### 조건이 뒤섞인 요구사항 정리 프롬프트
```

"사용자는 이메일로 로그인할 수 있고, 비밀번호는 8자 이상에 특수문자를 포함해야 한다.
단, 구글 소셜로그인 사용자는 비밀번호 규칙 대상이 아니다.
로그인 실패가 5회 누적되면 10분간 계정이 잠기지만, 관리자 계정은 잠금대상에서 제외된다. 
그리고 계정이 잠긴 상태에서도 비밀번호 재설정 요청은가능해야 한다.“
```
