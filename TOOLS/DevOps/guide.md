# DevOps 학습 자료
- DevOps에 대한 개념을 설명하는 자료
- DFR 프로젝트를 예시로 실습하는 과정
- pytest를 사용한 TDD 적용
- 단계별로 실습자료를 생성
  - 코드는 템플릿과 완성된 코드로 구분해서 작성
  - 실습 GUIDE등은 마크다운문서와 필요한 파일형태로 작성


- 실습 GUIDE의 문서 형식은 marp slide 형식 적용
  - dark-plus-code 테마 적용

## 기본 실습 환경
- python 3.11
- Django
- Django Rest Framework
- pytest
- github
- docker
