양자화(Quantization)의 핵심은 **"어떻게 하면 적은 비트(4비트 = 16개의 슬롯) 안에 원래 데이터(FP32)의 정보를 최대한 욱여넣을 수 있는가?"**에 있습니다. 이를 해결하는 두 가지 대표적인 방식인 **INT4**와 **NF4**의 원리를 자세히 비교해 드리겠습니다.

---

## 1. INT4 (4-bit Integer Quantization)

가장 전통적이고 직관적인 방식입니다. 부동소수점(Float) 값을 일정한 간격의 정수(Integer)로 매핑합니다.

### 원리: 선형 양자화 (Linear Quantization)

* **슬롯 배분:** 4비트는 $2^4 = 16$개의 숫자를 표현할 수 있습니다. INT4는 보통 $-8$부터 $7$까지(또는 $0$~$15$)의 정수 값을 가집니다.
* **매핑 과정:** 원래 데이터의 최솟값(min)과 최댓값(max)을 찾은 뒤, 그 사이를 **동일한 간격(Step size)**으로 16등분합니다.
  * 공식: $Q(x) = \text{round}(\frac{x}{scale} + zero\_point)$
* **특징:** 계산이 매우 단순하여 하드웨어 가속(GPU의 Tensor Core 등) 효율이 극대화됩니다.

### 한계점

딥러닝 모델의 가중치는 보통 0 근처에 몰려 있는 **정규분포** 형태를 띱니다. 하지만 INT4는 모든 구간을 동일한 간격으로 나누기 때문에, 데이터가 거의 없는 양 끝단(Outliers)에도 동일한 정밀도를 할당하고, 정작 데이터가 몰려 있는 중앙부의 세밀한 차이는 무시하게 되어 **양자화 오차(Quantization Error)**가 발생합니다.

---

## 2. NF4 (4-bit NormalFloat)

QLoRA 논문에서 제안된 방식이며, 현재 LLM 양자화의 표준처럼 쓰입니다. 데이터의 통계적 특성을 이용한 **비선형 양자화**입니다.

### 원리: 정규분포 최적화

* **가정:** 모델의 가중치는 평균이 0인 **정규분포 $N(0, 1)$**를 따른다고 가정합니다.
* **슬롯 배분 (Quantile Quantization):** 16개의 슬롯을 일정한 간격으로 나누지 않습니다. 대신, 정규분포의 **확률 밀도가 높은 곳(데이터가 많이 몰리는 0 근처)에는 슬롯을 촘촘하게 배치**하고, 데이터가 적은 양 끝단에는 슬롯을 넓게 배치합니다.
  * 이를 통해 각 슬롯이 담게 되는 데이터의 개수가 통계적으로 균등해지도록 설계합니다.
* **과정:**
  1. 표준 정규분포에서 누적 확률 밀도 함수(CDF)를 기준으로 16개의 최적의 '값'을 미리 계산합니다.
  2. 모델 가중치를 이 16개의 고정된 값 중 가장 가까운 값으로 매핑합니다.

### 특징

* **정보 보존:** 동일한 4비트를 쓰더라도 INT4보다 훨씬 많은 정보를 보존합니다. 가중치의 실제 분포에 최적화되어 있기 때문입니다.
* **추론 성능:** 비선형 방식이라 연산 자체는 복잡할 수 있지만, 추론 시에는 미리 계산된 조회 테이블(Look-up Table)을 사용하여 속도 저하를 최소화합니다.

---

## 3. 주요 차이점 요약

| 구분         | INT4 (Integer)      | NF4 (NormalFloat)            |
|:---------- |:------------------- |:---------------------------- |
| **핵심 개념**  | 균등한 간격으로 나눔 (선형)    | 데이터 분포 밀도에 따라 나눔 (비선형)       |
| **데이터 분포** | 균등 분포(Uniform)에 유리  | **정규 분포(Normal)에 최적화**       |
| **정밀도 유지** | 상대적으로 낮음 (정보 손실 발생) | **상대적으로 높음 (원래 성능 근접)**      |
| **주요 용도**  | 일반적인 하드웨어 가속 추론     | **LLM 파인튜닝(QLoRA) 및 효율적 추론** |

### 요약하자면

**INT4**는 "모든 칸을 똑같이 나누자"는 민주적인 방식이지만 효율이 떨어지고, **NF4**는 "사람이 많이 몰리는 곳에 정거장을 더 많이 세우자"는 데이터 중심적 방식입니다. 이 차이 덕분에 NF4는 4비트라는 극단적인 압축 환경에서도 모델의 지능을 놀랍도록 잘 유지합니다.
