## Q1. [단답형]
**대량의 데이터를 기반으로 사전 학습되어 다양한 작업에 범용적으로 활용될 수 있는 기초 모델을 지칭하는 용어는?**

- A. 파운데이션 모델 ✅ (정답)
- B. 강화학습 모델
- C. 앙상블 모델
- D. 판별 모델

**해설:** 파운데이션(foundation) 모델은 방대한 데이터로 사전 학습되어 여러 작업의 기초 역할을 하는 모델을 의미한다.

## Q2. [단답형]
**텍스트 파운데이션 모델의 3가지 핵심 구성 요소가 아닌 것은?**

- A. 빅데이터
- B. 자기 지도 학습(Self-supervised Learning)
- C. 트랜스포머(어텐션 기반 모델)
- D. 강화학습 전용 신경망 ✅ (정답)

**해설:** 3가지 구성 요소는 빅데이터, 자기 지도 학습, 어텐션 기반 트랜스포머 모델이다. 강화학습 전용 신경망은 해당하지 않는다.

---

## Q3. [단답형]
**모델과 데이터 규모가 커지면서 이전에 없던 능력이 갑자기 나타나는 현상을 무엇이라 하는가?**

- A. 과적합(Overfitting)
- B. 창발성(Emergent Property) ✅ (정답)
- C. 정규화(Regularization)
- D. 양자화(Quantization)

**해설:** 거대 언어 모델은 규모가 일정 임계점을 넘으면 이전 모델에는 없던 새로운 능력(창발성)이 나타나는 특징이 있다.

---

## Q4. [단답형]
**사람의 지도 없이, 입력 데이터 자체로부터 정답(레이블)을 만들어 학습하는 방식은?**

- A. 지도 학습
- B. 비지도 군집화
- C. 자기 지도 학습(Self-supervised Learning) ✅ (정답)
- D. 강화 학습

**해설:** 다음 토큰 예측처럼 데이터 자체에서 정답을 만들어 학습하는 방식이 자기 지도 학습이다.

## Q5. [단답형]
**보상 모델을 활용해 사람이 더 선호하는 응답을 생성하도록 추가 학습하는 방법은?**

- A. SFT(Supervised Fine-Tuning)
- B. RLHF(Reinforcement Learning from Human Feedback) ✅ (정답)
- C. Zero-shot Learning
- D. Beam Search

**해설:** RLHF는 지시 학습 이후, 보상 모델과 강화 학습을 통해 사람이 선호하는 응답을 생성하도록 추가 학습하는 방법이다.

## Q6. [단답형]
**확률이 높은 K개의 토큰만 후보로 두고, 그 안에서 확률에 따라 다음 토큰을 선택하는 디코딩 방식은?**

- A. Greedy Decoding
- B. Beam Search
- C. Top-K Sampling ✅ (정답)
- D. Top-P Sampling

**해설:** Top-K Sampling은 확률 상위 K개 토큰만 후보로 제한한 뒤 확률에 따라 무작위로 다음 토큰을 뽑는 방식이다.

## Q7. [문장형]
**LLM 학습 데이터가 폭발적으로 늘어난 이유로 가장 적절한 것은?**

- A. 인터넷의 방대한 텍스트를 수집·활용할 수 있게 되었기 때문이다 ✅ (정답)
- B. 모델 파라미터 수가 감소했기 때문이다
- C. 트랜스포머는 데이터 없이 학습이 가능하기 때문이다
- D. 사람이 모든 데이터에 정답을 직접 라벨링했기 때문이다

**해설:** 인터넷 텍스트 데이터 활용이 가능해지면서 학습 데이터 규모가 급증했다.

## Q8. [문장형]
**프롬프트 엔지니어링에서 Chain-of-Thought(CoT)에 대한 옳은 설명은?**

- A. 정답만 예시로 제시하고 추론 과정은 생략하는 기법이다
- B. 추론 과정을 예시에 포함해 단계적 사고를 이끄는 기법이다 ✅ (정답)
- C. 모델 파라미터를 직접 수정해 성능을 높이는 기법이다
- D. 사용자 질문을 삭제하고 시스템 프롬프트만 쓰는 기법이다

**해설:** CoT는 정답과 함께 추론 과정을 예시에 포함시켜 단계적 사고를 유도하는 기법이다.

## Q9. [문장형]
**LLM 평가 방법에 대한 설명으로 옳지 않은 것은?**

- A. 정답이 있는 문제는 정확도(Accuracy)로 평가할 수 있다
- B. 정답이 없는 개방형 과제는 사람이 직접 비교 평가할 수 있다
- C. LLM-as-judge는 평가 비용과 시간을 줄이는 방법 중 하나다
- D. LLM-as-judge는 편향이 없어 사람 평가를 완전히 대체한다 ✅ (정답)

**해설:** LLM-as-judge는 길이·순서·자기 선호 편향 등의 한계가 있어 사람 평가를 완전히 대체할 수 없다.

## Q10. [문장형]
**LLM의 한계로 언급되지 않은 것은?**

- A. 그럴듯한 거짓 정보를 만드는 환각(Hallucination) 현상
- B. 프롬프트로 안전장치를 우회하는 탈옥(Jailbreaking) 현상
- C. AI 생성 텍스트인지 판별하기 어려운 문제
- D. 학습 데이터가 적을수록 항상 더 정확해지는 문제 ✅ (정답)

**해설:** 언급된 한계는 환각, 탈옥, AI 텍스트 판별의 어려움이다. 데이터가 적을수록 정확도가 높아진다는 내용은 언급되지 않았고 사실과도 반대된다.
