# Lab 09. 관계 대수와 관계 해석

슬라이드: `09_관계대수.md`

관계 대수식을 SQL 로 옮겨 실행하고 결과를 확인한다.

## 1. 따라 하기

### 1-1. Select 와 Project

```
σ 학년≥3 (학생)
```

```sql
SELECT * FROM 학생 WHERE 학년 >= 3;     -- 4행, 5열
```

```
π 주소 (학생)
```

```sql
SELECT 주소 FROM 학생;                  -- 10행 (SQL 은 중복을 남긴다)
SELECT DISTINCT 주소 FROM 학생;         -- 6행 (관계 대수의 Project 결과)
```

### 1-2. 카티션 곱

```
학생 × 과목
```

```sql
SELECT COUNT(*) FROM 학생 CROSS JOIN 과목;   -- 60
SELECT * FROM 학생 CROSS JOIN 과목 LIMIT 1;  -- 컬럼 9개
```

차수는 5 + 4 = 9, 카디널리티는 10 × 6 = 60 이다.

### 1-3. 자연 조인과 동등 조인

```sql
SELECT * FROM 학생 NATURAL JOIN 학과 LIMIT 1;                           -- 컬럼 7개 (학과코드 1번)
SELECT * FROM 학생 s JOIN 학과 d ON s.학과코드 = d.학과코드 LIMIT 1;     -- 컬럼 8개 (학과코드 2번)
```

자연 조인은 중복 속성을 제거한다.

### 1-4. 디비전

"C101 과 C105 를 모두 수강한 학생"

```sql
SELECT 학번 FROM 수강
WHERE 과목코드 IN ('C101', 'C105')
GROUP BY 학번
HAVING COUNT(*) = 2;
```

| 학번 |
| --- |
| 1002 |
| 1007 |

이중 `NOT EXISTS` 로도 확인한다.

```sql
SELECT DISTINCT e.학번 FROM 수강 e
WHERE NOT EXISTS (
    SELECT 1 FROM 과목 c
    WHERE c.과목코드 IN ('C101', 'C105')
      AND NOT EXISTS (SELECT 1 FROM 수강 x
                      WHERE x.학번 = e.학번 AND x.과목코드 = c.과목코드));
```

### 1-5. 집합 연산

```
π 주소 (학생)  ∩  π 지역 (부서)
π 주소 (학생)  −  π 지역 (부서)
```

```sql
SELECT 주소 FROM 학생 INTERSECT SELECT 지역 FROM 부서;   -- 서울, 부산, 대전
SELECT 주소 FROM 학생 EXCEPT    SELECT 지역 FROM 부서;   -- NULL, 광주, 인천
```

### 1-6. Select 를 먼저 하는 것과 나중에 하는 것

```sql
EXPLAIN SELECT s.이름, e.점수
FROM 학생 s JOIN 수강 e ON s.학번 = e.학번
WHERE s.학년 = 1;
```

실행 계획의 첫 줄(`s`)에 `Using where` 가 보인다. 옵티마이저가 학생을 먼저 걸러 낸 뒤 수강과 조인한다. SQL 에 쓴 순서와 상관없이 "Select 를 먼저" 규칙이 적용된 것이다.
